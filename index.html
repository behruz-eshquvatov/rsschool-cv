Code Example

Solution to the "Persistent Bugger" kata on Codewars (JavaScript):

function persistence(num) {
  if (num < 10) return 0;
  const product = String(num)
    .split('')
    .reduce((acc, d) => acc * Number(d), 1);
  return 1 + persistence(product);
}

// Examples:
// persistence(39)  => 3  (3*9=27, 2*7=14, 1*4=4)
// persistence(999) => 4
// persistence(4)   => 0
